# Literotica Downloader V2

Download complete author libraries from Literotica using the modern `/api/3/` API. Supports ZIP, HTML, and EPUB export with series grouping, filtering, retry logic, and a user choice between combined files and separate chapter files.

## Install (SleazyFork)
- https://sleazyfork.org/en/scripts/577945-literotica-downloader-v2

## Install
- Chrome + Tampermonkey: install the userscript from SleazyFork, or install locally from `dist/literotica-downloader-tampermonkey.user.js`.
- Firefox + Greasemonkey: install the userscript from SleazyFork, or install locally from `dist/literotica-downloader-greasemonkey.user.js`.

## Use
- Open an author page (e.g. `https://www.literotica.com/authors/...`) or a member story listing page (`/stories/memberpage.php`).
- Use the "Literotica Downloader v2" panel to load the catalog, filter/select stories, choose an export format, choose `Combined Files` or `Separate Chapters`, and download.
